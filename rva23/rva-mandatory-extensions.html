RVA profile mandatory extensions compared

The ISA extensions that each user-mode RVA profile (RVA20U64, RVA22U64, RVA23U64) makes mandatory, side by side, with RV64GC as the baseline column. Extensions that a profile only lists as an option are counted as no.

Reading notes

  • RVA20U64 is almost RV64GC. In instruction terms it drops fence.i and adds the Zicntr counters. The other five additions (Ziccif, Ziccrse, Ziccamoa, Zicclsm, Za128rs) are guarantees about main memory and LR/SC behaviour, which RV64GC leaves unspecified.
  • Zifencei is left out of every user-mode profile on purpose. fence.i only synchronises the hart that executes it, and the OS can migrate the thread afterwards, so the profile text says the instruction cache flush should always go through an OS call. On Linux that is the riscv_flush_icache syscall or vDSO call. Zifencei is mandatory in the supervisor-mode profiles (RVA20S64, RVA22S64, RVA23S64).
  • Za128rs after RVA20. RVA22U64 tightened the limit to Za64rs, and its text names only that. A reservation set of at most 64 bytes also meets the 128-byte limit, so the row stays yes.
  • B in RVA22U64. At ratification the profile listed Zba, Zbb and Zbs one by one because B had not been defined yet. The current text says mandating B is equivalent.
  • Implied sub-extensions have no rows. Zmmul (from M), Zaamo and Zalrsc (from A), and Zca and Zcd (from C with D) apply to all four columns. In RVA23U64, V also brings Zve32x, Zve32f, Zve64x, Zve64f, Zve64d, Zvl32b, Zvl64b and Zvl128b, and Zvbb brings Zvkb.
  • Promoted from option to mandatory: Zihpm was an RVA20U64 option and is mandatory from RVA22U64. V was an RVA22U64 option and is mandatory in RVA23U64.
  • Ratified profile text: riscv/riscv-profiles, src/profiles.adoc (RVA20U64, RVA22U64) and src/rva23-profile.adoc (RVA23U64, ratified in commit 0273f3c921b6).
  • Extension lists cross-checked against riscv/riscv-unified-db at upstream main 7914a5845eb4 (2026-09-23).
  • Definition of G as IMAFD, Zicsr, Zifencei: riscv/riscv-isa-manual, src/unpriv/rv-32-64g.adoc.
